One joke. One line. No setup left over.

## The joke

> I told my laptop I needed space, so it deleted all my files — apparently it took the breakup harder than I did.

A breakup line taken literally by the one machine that should know
better. Setup, twist, and punchline land in a single read.

## How it works

`main.py` writes exactly one line (at most 200 characters) to
`/output/entry.txt`. It asserts the line has no newline inside it and
stays within the 200-character limit before writing.

```sh
python3 main.py
cat /output/entry.txt
```
